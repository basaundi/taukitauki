Flick-input Basque keyboard with word prediction and mutation swap.

## Full description

TaukiTauki is a flick-input keyboard built for the Basque language (euskara). Instead of hunting for small keys, you swipe in one of eight directions from each key to reach syllables, letters, and punctuation — fast, natural, and thumb-friendly.

**Flick input**
Each key holds a full syllable at its centre and related characters in the eight flick directions. Type "ta" with a tap, "tu" with a flick up, "ti" with a flick left. Fewer taps, more words.

**Basque-first design**
The default layout is built around Basque syllable patterns: ka/ke/ki/ko/ku, za/ze/zi/zo/zu, and so on. A QWERTY mode is also available for writing in other languages.

**Word prediction**
As you type, TaukiTauki suggests completions drawn from a local Basque dictionary. When you finish a word, the next suggestions are powered by bigram frequency — the keyboard learns what words tend to follow each other.

**Mutation swap**
Basque grammar requires consonant mutations (e.g. k → g, t → d, s → ts). The swap key cycles the last-typed consonant through its mutation pair, so you never have to delete and retype.

**Completely private**
No keystrokes are ever recorded or transmitted. All prediction happens on-device using a bundled SQLite database. No internet permission is requested or used.

**Open source**
TaukiTauki is free and open source. Source code and build instructions are available on GitHub.
